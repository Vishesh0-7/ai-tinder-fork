# ai-tinder
AI-generated tinder frontend.

## Test Suite

This repository now includes comprehensive backend and frontend test coverage with Jest.

### Install

Run from the repository root:

```bash
npm install
```

### Run all tests

```bash
npm test
```

### Run coverage

```bash
npm run test:coverage
```

Coverage output is written to the coverage folder, including an HTML report at coverage/lcov-report/index.html.
